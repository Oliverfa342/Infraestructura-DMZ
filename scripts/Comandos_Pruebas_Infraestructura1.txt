ip route

WEB-CAJA (10.15.72.2):

apk update

WEB-INVENTARIO (10.15.72.3):

DB-SERVER (10.15.72.4):

mariadb -e "SELECT nombre,precio,stock FROM redes1571.productos;"
mariadb -e "SELECT * FROM redes1571.ventas;"

FORTIGATE (interfaz grafica):
Network > Interfaces
Policy & Objects > Firewall Policy
Security Profiles > Web Filter
Log & Report > Forward Traffic
Log & Report > Web Filter

Resultados observados:
- La VLAN 10 visualiza la pagina de violacion al intentar visitar Inventario.
- La VLAN 20 puede iniciar SSH hacia el servidor de base de datos.
- Las peticiones de Internet no autorizado desde DMZ aparecen DENY en logs.
- Caja registra una venta y MariaDB almacena el movimiento.
